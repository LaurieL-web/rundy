# 🏃 Rundy

**Rundy** est une application web qui génère des programmes d'entraînement de course à pied personnalisés grâce à l'intelligence artificielle.

Projet développé dans le cadre de la formation AI Software Development [Le Wagon](https://www.lewagon.com), en équipe de 4.

## 🎯 Objectif

Permettre à chaque coureur, débutant ou confirmé, d'obtenir un plan d'entraînement adapté à son niveau et à ses objectifs, généré automatiquement par IA.

## ⚙️ Fonctionnalités

- Génération de programmes de course personnalisés via IA
- Interface web responsive et interactive
- Gestion des utilisateurs et de leurs profils d'entraînement

## 🛠️ Stack technique

| Catégorie | Technologies |
|---|---|
| Back-end | Ruby on Rails |
| Front-end | JavaScript, HTML, CSS, SCSS, Bootstrap, Turbo |
| Base de données | PostgreSQL|
| Outils | Git / GitHub |

## 👥 Équipe

Projet réalisé en équipe de 4 développeurs, dans une logique agile, avec répartition des tâches entre back-end, front-end et intégration IA.

## 💡 Mon rôle

- Conception et développement de l'application
- Développement des fonctionnalités IA et intégration des différentes parties de l'application
- Mise en pratique des technologies et méthodes vues pendant la formation

## 🚀 Installation

```bash
git clone https://github.com/LaurieL-web/rundy.git
cd rundy
bundle install
rails db:create db:migrate
rails server
```

L'application est ensuite accessible sur `http://localhost:3000`.
