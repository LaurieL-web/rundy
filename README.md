# 🏃 Rundy

**Rundy** is a web application that generates personalized running training plans powered by artificial intelligence.

Developed in **just one week** as part of a **4-person team** during the AI Software Development Bootcamp at [Le Wagon](https://www.lewagon.com).

## 🎯 Goal

Help every runner—from beginner to advanced—get a tailor-made training plan adapted to their fitness level, race goal, and schedule, generated automatically via AI.

## ⚙️ Key Features

- AI-powered personalized running plan generation
- Interactive multi-step onboarding & goal setting
- Personal dashboard ("My Plan") to track training schedules
- Responsive & interactive web interface

## 🛠️ Tech Stack

| Category | Technologies |
|---|---|
| Back-end | Ruby on Rails |
| Front-end | JavaScript, HTML, CSS, SCSS, Bootstrap, Turbo |
| Database | PostgreSQL |
| Tools & Deployment | Git / GitHub, Heroku |

## 👥 Team

Developed as part of a team using an agile methodology, with tasks divided across back-end, front-end and feature integration.

## 💡 My Role

- 🤖 **AI Training Plan Generation:** Built the core logic to prompt and stream personalized running plans using LLM integration.

- 📝 **Goal Creation Flow:** Developed the user onboarding form (front & back) to capture race distance, target time, preparation duration and training frequency.

- 📊 **Program Dashboard:** Designed and implemented the "Mon Programme" (My Training Plan) page (front & back).

- 🤝 **Git Workflow:** Coordinated code integration, feature branches, and PR reviews within a 4-person team.


## 🚀 Getting Started

```bash
git clone [https://github.com/LaurieL-web/rundy.git](https://github.com/LaurieL-web/rundy.git)
cd rundy
bundle install
rails db:create db:migrate
rails server
```

The application will be available at http://localhost:3000.
